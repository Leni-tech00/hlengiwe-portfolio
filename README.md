# CyberAI Portfolio

Create a premium modern personal portfolio website for an aspiring cybersecurity and AI professional. I want it to feel creative, futuristic and technology-focused while remaining professional enough to send to employers. Use a dark modern interface, subtle gradients and glow effects, glass-style cards, smooth scrolling and tasteful micro-animations. Avoid making it look overly flashy or like a gaming website.

Create sections for Home, About Me, Technical Skills, Soft Skills, Projects, Education, Certifications, Work Experience and Contact. Include a Download CV button and links to GitHub and LinkedIn.

The website must be fully responsive on desktop, tablet and mobile. Make the hero section visually impressive and make the Projects section one of the main visual features of the website.
